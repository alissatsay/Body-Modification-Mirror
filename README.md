# Digital Mirror

This repo contains two related but independent computer-vision projects,
both built around a camera-based "digital mirror" that changes how a
person's body appears to them in real time. They share an origin (MediaPipe
pose tracking + person/background segmentation) but serve different
purposes, audiences, and papers — they're kept in separate folders on
purpose, and neither depends on the other.

Both grew out of the same senior thesis project — see
[`Alissa_Tsay_Thesis_Paper.pdf`](Alissa_Tsay_Thesis_Paper.pdf) and
[`Alissa_Tsay_Poster.pdf`](Alissa_Tsay_Poster.pdf) for the full writeup and
the presentation poster.

## [`clinical_mirror/`](clinical_mirror/) — the clinical mirror

A Gaussian pixel-warp mirror (stretches/compresses a region of the body
around the hips) used for an HSRC-approved user study and ongoing
pre-clinical work, with a CHI paper in progress. See
[`clinical_mirror/README.md`](clinical_mirror/README.md) for the file
breakdown, controls, and how to run it.

## [`installation_mirror/`](installation_mirror/) — Reshape Repeat

A skeleton-tracked triangular mesh with ARAP (as-rigid-as-possible)
deformation, sculpted live via two-hand gestures (pinch, drag, brush). This
is "Reshape Repeat," the interactive installation that's been exhibited
publicly. An earlier code snapshot of this was submitted to SIGGRAPH (that
submission has since been deprioritized). See
[`installation_mirror/README.md`](installation_mirror/README.md) for the
file breakdown, the pipeline's history, and how to run it.

## Setup

Requires Python 3.8+.

```
python3 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip setuptools wheel
pip install -r requirements.txt
```

Both mirrors are run the same way — from the repo root, with the virtual
environment active:

```
python clinical_mirror/live_mirror.py
python installation_mirror/run_installation.py
```

Both will ask you to step out of frame at startup to capture a clean
background, then start the mirror. Press `q` to quit either one.

## Repo layout

```
clinical_mirror/               the clinical warp mirror (HSRC study, CHI paper)
installation_mirror/           the Reshape Repeat mesh-sculpting installation
requirements.txt               shared Python dependencies for both projects
Alissa_Tsay_Thesis_Paper.pdf   the senior thesis writeup covering both mirrors
Alissa_Tsay_Poster.pdf         the thesis presentation poster
```

Generated data folders (`images_for_warping/`, `warped_dataset*`,
`saved_frames/`, `installation_mirror/assets/background_captures/`) are
gitignored — they're regenerated by running the scripts, not something you
need to check out or commit.
